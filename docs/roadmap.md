# Roadmap

1. Milestone 1 — Windows-native FastAPI, metrics, Prometheus, tests.
2. Milestone 2 — Grafana native Windows dashboard + basic alert thresholds.
3. Milestone 3 — Kubernetes using minikube Hyper-V or VirtualBox (no WSL).
4. Milestone 4 — Generate and label incident data; create baseline alerts.
5. Milestone 5 — Python / scikit-learn anomaly detector and evaluate against baseline.
6. Milestone 6 — Policy-based remediation recommendations with dry-run by default.
7. Milestone 7 — Tested, narrow, audited actions in disposable Kubernetes cluster; public demo.

Do not deploy auto-remediation to a real production cluster.
